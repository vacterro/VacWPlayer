# WildRiftAssistant

Один гуй на весь обвес для Wild Rift, шоб не лезть руками в скрипты. Педали, ротации под каждого додика в игре, сворачивание окна если сдох, и автопрожим кнопок после катки. 

## Че умеет

- **База (Main)** — глобальные рубильники: мышку перебиндить, пробел спамить, чтоб за АФК не кикнули, пауза на ручной прицел, и список своих комбух. Можешь добавлять, удалять или вообще сбросить всё в дефолт.
- **Вкладка Ryze** — зашиты ротации на крипов, лес и замесы.
- **Вкладка Xin Zhao** — врыв с E->W->Q по мете, шоб не тупил.
- **Мониторы смерти / Авто-рега** — рулят скриптами `deathwatch.py` / `autocontinue.py`. Перехватывают управление чисто, без костылей (`--replace`).
- **Режим Чемпа** — выбираешь одного, и педали (F13–F15) работают только для него. Никакой каши.
- **Тайминги** — пишешь `кнопка:мс`, типа `q,e:120,{Space}:200`. Всё.
- **Трей** — крестик не убивает прогу, а прячет в трей. Жми Quit, если надо вырубить наглухо.

## Че надо

- Windows, Python 3.11, виртуалка проекта (`../venv`).
- AutoHotkey v1 лежит рядом как `AutoHotkeyU64.exe` — ставить отдельно не надо, не тупи.
- `pip install -r requirements.txt`.

## Как заводить

Просто дважды щёлкни **`WildRiftAssistant.bat`** (сам найдёт venv, без консольного окна).
Или вручную:

```
..\venv\Scripts\pythonw.exe main.pyw
```
Выбираешь чемпа, настраиваешь вкладки, жмешь **Погнали**.

## Тесты

```
python -m pytest tests/ -v
```
Нужен pytest. Он тупо импортит модули и проверяет, что ты там не насрал в коде.

## Как эта шарманка пашет

Гуй сам кнопки не перехватывает — он рожает файл `wr_runtime.ahk` из конфига и дергает AutoHotkey (режим Event, BlueStacks по-другому не жрет). Убивает только СВОЙ процесс по PID, чужие скрипты не трогает. Старый костыль `wr.ahk` сносится автоматом.

Три конфига, каждый делает свое дело: `config.json` (комбухи и рубильники), `deathwatch_config.json` (палит смерть), `autocontinue_config.json` (тыкает кнопки после катки). `wr_runtime.ahk` рождается сам — руками его не трогай, сломаешь.

## Как писать комбо

Через запятую. `{Space}`, `f`, буквы. Скиллы (q/w/e/r) кастуются на себя (с шифтом), если рубильник не выключишь. Пиши `:ms` после кнопки для паузы. Зажмешь педаль — будет лупить по кругу.
