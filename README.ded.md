# VacWPlayer

**v0.3.39** — [Что поменялось](CHANGELOG.md)

Один гуй на весь обвес для Wild Rift, шоб не лезть руками в скрипты. Педали, ротации под каждого додика в игре, сворачивание окна если сдох, и автопрожим кнопок после катки. 

## Че умеет

- **База (Main)** — глобальные рубильники: мышку перебиндить, пробел спамить, чтоб за простой не кикнули, пауза на ручной прицел, и список своих комбух. Можешь добавлять, удалять или вообще сбросить всё в дефолт.
- **Вкладка Champions** — ротации под каждого чемпа (Wave/Jungle/PVP). Зашиты готовые комбо для Ryze, Xin Zhao, Yasuo, Master Yi и др., на остальной ростер — редактируемые заглушки.
- **Вкладка AFK Farm** — гоняет по точкам на миникарте: жмёт точку, идёт, лупит комбо, и так по кругу.
- **Мониторы смерти / Авто-рега** — рулят скриптами `deathwatch.py` / `autocontinue.py`. Перехватывают управление чисто, без костылей (`--replace`).
- **Вкладки Buy / Accept / Surrender** — автопокупка по золоту после отхода (`digit_reader`), авто-приём матча и голосование за сдачу. У каждой свой мотор (`deathwatch_config.json`, `accept.py`, `surrender.py`).
- **Миникарта** — хоткеи для перемещения по линиям, строки можно перетаскивать.
- **Режим Чемпа** — выбираешь одного, и педали (F13–F15) работают только для него. Никакой каши.
- **Тайминги** — пишешь `кнопка:мс`, типа `q,e:120,{Space}:200`. Всё.
- **Трей** — крестик прячет прогу в трей и глушит движок (wr_runtime.ahk закрывается вместе с окном). Жми Quit, если надо вырубить всё наглухо.
- **Вики** — архитектура, справочник конфига, гайд по вкладкам: `docs/wiki/`.

## Че надо

- Windows, Python 3.11, виртуалка проекта (`../venv`).
- AutoHotkey v1: `AutoHotkeyU64.exe` рядом с прогой, иначе штатная установка в `C:\Program Files\AutoHotkey\`.
- `pip install -r requirements.txt`.

## Как заводить

Дважды щёлкни **`VacWPlayer.vbs`** (консоль спрятана, запускается тихо). Нужны ошибки на экране — жми **`VacWPlayer.bat`** (плюс `--check`). Оба сами найдут venv.
Или вручную:

```
..\venv\Scripts\pythonw.exe main.pyw
```
Выбираешь чемпа, настраиваешь вкладки, жмешь **Погнали**.

## Отказ от ответственности

Эта программа автоматизирует игровые действия (нажатия клавиш, клики мыши, распознавание экрана).
**Использование автоматизации в League of Legends: Wild Rift нарушает Условия обслуживания Riot Games.**
Фичи типа Rotating Farm, Idle Prevention, авто-приём/сдача и автоматизация смерти могут привести
к блокировке аккаунта или перманентному бану. Пользуешься на свой страх и риск.

## Тесты

```
python -m pytest tests/ -v
```
Нужен pytest. Он тупо импортит модули и проверяет, что ты там не насрал в коде.

## Как эта шарманка пашет

Гуй сам кнопки не перехватывает — он рожает файл `wr_runtime.ahk` из конфига и дергает AutoHotkey (режим Event, BlueStacks по-другому не жрет). Убивает только СВОЙ процесс по PID, чужие скрипты не трогает. Старый костыль `wr.ahk` сносится автоматом.

Пять конфигов, каждый делает свое дело: `config.json` (комбухи и рубильники), `deathwatch_config.json` (палит смерть), `autocontinue_config.json` (тыкает кнопки после катки), `accept_config.json` (принятие матча), `surrender_config.json` (голосование за сдачу). `wr_runtime.ahk` рождается сам — руками его не трогай, сломаешь.

## Как писать комбо

Через запятую. `{Space}`, `f`, буквы. Скиллы (q/w/e/r) кастуются на себя (с шифтом), если рубильник не выключишь. Пиши `:ms` после кнопки для паузы. Зажмешь педаль — будет лупить по кругу.
