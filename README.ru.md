# VacWPlayer

**v0.3.13** — [Что поменялось](CHANGELOG.md)

Единый винтажный интерфейс для всего инструментария Wild Rift: комбо на педалях, ротации под каждого чемпиона, автосворачивание при смерти и автопродолжение после матча — управляемый «супер AHK» с графическим интерфейсом без ручного редактирования скриптов.

## Особенности

- **Вкладка Main (Главная)** — глобальные переключатели (переназначение мыши, спам пробела, предотвращение простоя, кнопка остановки, пауза для ручного прицеливания, процесс игры) плюс список кастомных комбо режима General: добавление, удаление, очистка, привязка триггера по нажатию, сброс к старым настройкам по умолчанию.
- **Вкладка Champions (Чемпионы)** — ротации Wave / Jungle / PVP для каждого чемпиона. Проверенные комбо предзагружены для Райза, Синь Чжао, Ясуо, Мастера Йи и других; комбо-заглушки для всего ростера Wild Rift — редактируются, с пресетами.
- **Вкладка AFK Farm (Ферма)** — цикл по точкам миникарты, движение + комбо, повтор.
- **Вкладки Death Watch / Auto Continue** — управляют существующими движками `deathwatch.py` / `autocontinue.py` (тестовый режим, текущий статус), каждый из которых чисто перехватывает управление через `--replace`.
- **Режим чемпиона (Champion mode)** — выпадающий список выбирает ровно один активный набор комбо, чтобы педали (F13–F15) никогда не конфликтовали.
- **Задержки на каждый шаг** — синтаксис `клавиша:мс`, например `q,e:120,{Space}:200`.
- **Иконка в трее** — крестик сворачивает в трей, движок продолжает работу; кнопка Quit останавливает всё.
- **Wiki** — архитектура, справочник конфигурации, руководство по вкладкам: `docs/wiki/`.

## Требования

- Windows, Python 3.11, виртуальное окружение проекта (`../venv`).
- AutoHotkey v1, идущий в комплекте как `AutoHotkeyU64.exe` — отдельная установка не требуется.
- `pip install -r requirements.txt`.

## Запуск

Двойной клик по **`VacWPlayer.vbs`** — запуск без консоли (окно скрыто,
приложение стартует тихо). Или запусти **`VacWPlayer.bat`** вручную для
видимых ошибок / диагностики `--check`. Оба сами находят venv. Вручную:

```
..\venv\Scripts\pythonw.exe main.pyw
```

Набор комбо по умолчанию (Ryze) запускается автоматически. Отредактируйте любую вкладку, выберите чемпиона и нажмите **Run** (Применить и запустить).

## Дисклеймер

Этот инструмент автоматизирует игровые действия (нажатия клавиш, клики мыши, распознавание экрана).
**Использование ПО для автоматизации в League of Legends: Wild Rift нарушает Условия использования
Riot Games.** Функции вроде Rotating Farm, Idle Prevention, авто-принятия/сдачи и автоматизации
при смерти могут привести к блокировке или бану аккаунта. Используйте на свой страх и риск.

## Тесты

```
python -m pytest tests/ -v
```

Требуется pytest (`pip install pytest` или `pip install -r requirements.txt`).
Тесты импортируют модули без графического интерфейса и проверяют, что все .py файлы компилируются без ошибок.

## Как это работает

Графический интерфейс сам никогда не перехватывает клавиши — он генерирует `wr_runtime.ahk` из `config.json` с помощью `ahk_generator.py` и запускает AutoHotkey (режим Event, необходимый для BlueStacks). Только запущенный НАМИ процесс отслеживается и убивается по PID; другие скрипты AHK остаются нетронутыми. Старый рукописный `wr.ahk` автоматически выводится из эксплуатации при запуске.

Пять конфигов, у каждого своя задача: `config.json` (комбо, режимы, переключатели), `deathwatch_config.json` (детекция смерти), `autocontinue_config.json` (кнопки после матча), `accept_config.json` (принятие матча), `surrender_config.json` (голосование за сдачу). `wr_runtime.ahk` генерируется автоматически — никогда не редактируйте его вручную.

## Синтаксис комбо

Клавиши через запятую. `{Space}`, `f`, буквы. Буквы способностей q/w/e/r кастуются с шифтом (на себя), если опция "Shift-cast" не выключена. Добавьте `:ms` к клавише для задания задержки конкретного шага; иначе применяется общий интервал комбо. Удерживайте педаль для зацикливания.
